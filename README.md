# WeatherGPT — SIH26068

AI-powered weather intelligence web application built for Smart India Hackathon 2026.

WeatherGPT combines live weather data, an AI conversational assistant, historical climate analysis, and sector-specific weather advisories into a single dashboard — with support for both English and Hindi, including voice input and output.

---

## Features

- **Live weather dashboard** — current conditions, feels-like temperature, humidity, wind, precipitation, and a 7-day forecast
- **AI weather chat (WeatherGPT)** — conversational assistant powered by Google Gemini, with real function-calling tools for current weather, forecasts, alerts, and impact analysis
- **Weather alerts** — automatically generated RED/ORANGE/YELLOW/GREEN alerts based on live and forecast conditions
- **Interactive map** — city-level weather markers across major Indian cities, built with Leaflet and OpenStreetMap
- **Climate analysis** — 30-day historical temperature and rainfall trends, sourced from the Open-Meteo Archive API
- **Sector advisory** — weather-based guidance for Agriculture, Aviation, Marine, and Urban sectors, each with a computed risk level and recommendations
- **Bilingual support** — English and Hindi (हिंदी) for both text and voice interaction
- **Voice input & output** — browser-based speech recognition and text-to-speech
- **Session-based conversation memory** — the AI assistant retains context across a conversation, with location carryover for natural follow-up questions

---

## Tech Stack

**Frontend**
- React (Vite)
- react-leaflet + Leaflet (interactive map)
- Custom SVG charts (temperature & rainfall trends, no external chart library)
- Browser Speech Recognition & Speech Synthesis APIs

**Backend**
- FastAPI (Python)
- Google Gemini (Gemma) — conversational AI with function calling
- Open-Meteo API — live weather & forecast data
- Open-Meteo Archive API — historical climate data
- Open-Meteo Geocoding API — location resolution

## Local Setup

### Prerequisites
- Python 3.10+
- Node.js 18+
- A Google Gemini API key ([Google AI Studio](https://aistudio.google.com/))

### 1. Clone the repository

```bash
git clone https://github.com/vishalxop725-rgb/weathergpt-sih26068-.git
cd weathergpt-sih26068-
```

### 2. Backend setup

```bash
cd backend
python -m venv venv

# Activate the virtual environment
# Windows:
venv\Scripts\activate
# macOS/Linux:
source venv/bin/activate

pip install -r requirements.txt
```

Create a `.env` file in the `backend/` folder (use `.env.example` as a reference):

```
GEMINI_API_KEY=your_gemini_api_key_here
```

Start the backend server:

```bash
uvicorn main:app --reload
```

The backend will run at `http://127.0.0.1:8000`. You can view the interactive API docs at `http://127.0.0.1:8000/docs`.

### 3. Frontend setup

Open a new terminal:

```bash
cd frontend
npm install
npm run dev
```

The frontend will run at `http://localhost:5173` (or `5174` if `5173` is in use).

### 4. Open the app

Visit `http://localhost:5173` in your browser. The frontend is pre-configured to talk to the backend at `http://127.0.0.1:8000`.

## API Endpoints

| Method | Endpoint | Description |
|--------|----------|-------------|
| GET | `/` | Health/status check |
| GET | `/api/health` | Detailed health check, including AI status |
| GET | `/api/weather` | Current weather + 7-day forecast (Delhi) |
| GET | `/api/alerts` | Generated weather alerts |
| GET | `/api/climate?location=&days=` | Historical climate data |
| GET | `/api/advisory?location=` | Sector-based weather advisory |
| GET | `/api/weather/cities` | Multi-city weather for the map |
| POST | `/api/chat` | AI conversational weather assistant |
| POST | `/api/chat/clear` | Clear a chat session's memory |

## Notes

- Weather alerts and advisories generated by WeatherGPT are informational and are **not official government warnings**.
- The default location is Delhi; any other location can be resolved via the built-in geocoding lookup.
- All weather and climate data is sourced from [Open-Meteo](https://open-meteo.com/), a free and open-source weather API.
